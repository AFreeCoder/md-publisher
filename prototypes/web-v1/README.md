# 锦章网页版视觉提案 01

状态：待用户评审。依据 Issue #5 与 `b1450a4` 中已评审的 `docs/design/product-v1/web.md`，本目录是设计稿，不替代技术方案，也不代表产品已实现。

## 查看

直接用浏览器打开本目录 `index.html`，或在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototypes/web-v1
```

打开 `http://127.0.0.1:8765/#home` 查看门户，`#format` 查看工作区。

- `home.png`：门户整页。
- `workspace.png`：桌面工作区。
- `mobile.png`：390px 窄屏工作区。
- `zhihu-confirm.png`：知乎图片中转确认。

上述 PNG 保留首版暖白背景用于对比；当前 HTML 已按用户反馈切换纯白底色。

## 评审范围

纯白底色、墨色文字、朱砂强调色；门户用书页与印章呼应品牌，工具页优先保证原文和预览的阅读空间。三套主题名称与视觉均为提案，尚未锁定。

可体验平台和主题切换、固定开头结尾、固定文案、标题采用一级标题、封面选择，以及窄屏设置面板。右下角「评审状态」可展示缺图、远程图片降级、复制失败、任务失效与空白状态。

渲染仅支持本示例需要的基础语法；图片使用 CSS 示意图，插图用示例替代。未接入 core、图片文件读写、存储、上传、实际剪贴板写入或平台投递。统计体积与结果文案为标明的演示数据；刷新会恢复示例。「全选预览区正文」可真实选中正文，未验证目标平台粘贴结果。Skill 安装命令与 BRAT 地址等待真实发行信息，不虚构安装入口。

正式产品仍需使用定稿的 Next.js / core 方案实现；请评审页面信息层次、品牌视觉、主题方向与异常反馈是否符合预期。
